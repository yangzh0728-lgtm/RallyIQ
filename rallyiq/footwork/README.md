# 脚步分析（footwork）

从姿态模型的两个脚踝关键点出发，把双脚投影到球场平面（米），再和修正后的击球对齐。纯 numpy，每次请求现算
（`GET /api/videos/{id}/footwork`，3 分钟 30fps 视频约 0.3 秒）。

装了脚部模型时，流水线的 `feet` 阶段还会给出每位球员的**脚跟和脚尖**（足底），用来判断脚尖朝向和哪一部分先着地，见下文
“脚跟 / 脚尖”。没有这个阶段的结果时，其余分析照常只用脚踝。

## 怎么算

| 输出 | 方法 |
| --- | --- |
| 触地（contact） | 脚踝下移约 8 cm 得到着地点；按“球员所在位置每米多少像素”换算出脚的图像速度（m/s），低于 0.55 m/s 记为着地、高于 1.0 m/s 记为离地（滞回）。用图像速度而不是球场速度，是因为低机位下远端球员纵向走一步只动几个像素，但抬脚仍然明显。左右脚被姿态模型互换时按帧间距离纠正。 |
| 步（step） | 同一只脚相邻两次着地之间的球场位移 ≥ 0.18 m（远端误差大时按 3 倍定位误差放宽）。 |
| 启动步（split step） | 双脚在去掉慢速趋势后同时上升、再同时下落（小跳）；落地时刻相对对手击球在 −0.1～+0.3 秒为“及时”，更早为“偏早”，更晚为“偏晚”；对手击球前后 0.45 秒内没有小跳为“没有”。职业比赛（ShuttleSet st07_set1，有人工标注的击球时刻）上落地集中在对手击球后 +120～+280 ms。 |
| 起动（reaction） | 对手击球后，双脚中点朝自己下一拍击球位置的速度持续 0.1 秒超过 1 m/s 的时刻；0 表示对手击球时已经在朝那个方向移动。 |
| 步法 | 沿移动方向看：后脚追上前脚但不超过 = 并步；后脚越过前脚且横向或后退 = 交叉步；向前 = 跑动。 |
| 弓步 / 起跳 | 击球时两脚相距 ≥ 1 m 且最后一步 ≥ 0.5 m = 弓步；双脚同时离地 0.2～0.9 秒且抬高 ≥ 12 cm = 起跳。 |
| 回位 | 击球后多久回到本方中心（中线、离底线 3.6 m，半径 1 m）；对手下一拍出手时离中心多远。 |

每位球员给出 `jitter_m`（着地时脚的抖动，米）：近端一般 0.03–0.05 m，远端低机位约 0.1 m，此时结果标为“只作参考”。

所有窗口和容差都按秒设定（击球帧对齐 0.07 秒、起跳归属 0.1 秒等），同一段动作用 30 fps 或 60 fps 拍，判断一致（`tests/footwork/test_fps.py`）。

## 脚跟 / 脚尖（足底，`sole.py`）

| 输出 | 方法 |
| --- | --- |
| 关键点 | `feet` 阶段：对每个球员框跑 BlazePose GHUM full（MediaPipe 的单人关键点模型，Apache-2.0，本地运行，每人每帧约 8 ms），取脚踝、脚跟、脚尖；只跑回合内（前后各留 1 秒）。被近端球员挡住脚的远端球员那一帧跳过。模型的左右脚按它自己的脚踝和已跟踪的脚踝配对，不会和左右互换混在一起。 |
| 脚尖朝向（`toe_dir_deg`） | 脚放平时脚跟和脚尖都在地面上，投影到球场就是脚的方向；本人视角 0° = 朝网，+90° = 朝本人右侧。投影出的脚长不像一只鞋（不在 0.14–0.42 m）时不给方向；某位球员的典型脚长不对（低机位远端）就整个人都不判断。 |
| 着地方式（`landing`） | 脚落稳前后 0.1 秒内，脚尖比“脚跟着地、脚放平”时该在的位置高出多少（米，按该处图像比例换算）：脚尖高 = 脚跟先着地，脚跟高 = 前脚掌先着地，都不明显 = 全脚掌。阈值取 4 cm 和该脚放平时读数波动的 2.5 倍中较大的一个。 |
| 弓步前脚 | 弓步最后一步那只脚的着地方式，以及脚尖和跨步方向的夹角（只判断向前和向两侧的弓步；向后撤成大跨步时脚尖本来就不朝跨步方向）。 |

DJI_0009（近端 P1，30fps）：抽查 16 次脚跟先着地 / 前脚掌先着地的判断，11 次和画面一致，其余多是画面里看不清；
0:44 的弓步判为脚跟先着地，和画面一致。远端 P2 的脚长投影不稳定，自动不判断。

## 用在哪里

- 赛后统计：`P1.footwork.*`（启动步比例与时机、起动、回位、步数、弓步、起跳、最快速度、步法分布）；有脚跟 / 脚尖时另有
  `heel_first_pct`（移动中脚跟先着地的比例）、`landings`（着地方式分布）、`lunge_heel_first_pct`、`lunge_toe_off_deg`。
- 教练重点：启动步少 / 时机不对、回位慢、起动慢、移动中常用脚跟先着地、弓步脚尖不对准跨步方向或不是脚跟先着地 → 检索
  `split_step` / `footwork` 教学笔记。
- 逐拍建议：每条都带击球者这一拍的脚步；另有两条脚步规则 `slow_recovery`（回位慢被对手调动或进攻）和 `late_start`（没有启动步且起动慢）。
- 工作台：视频上的脚印（实心 = 着地，空心 = 刚离地；有脚跟 / 脚尖时脚印按鞋的方向画，黑点是脚尖）和动作标签、时间线上的
  “启 / 弓 / 跳”标记、脚步面板（含着地方式）。

## 局限

- 着地点仍用脚踝：在 DJI_0009 上脚跟 / 脚尖的位置抖动（近端约 0.07–0.09 m）不比脚踝小，所以它们只用来判断方向和着地方式。
- 着地方式在 30 fps 下只有 3–6 帧可看，单次判断只作参考，看比例更可靠；远端球员目前判断不了。同一次弓步在 30 fps 和 60 fps 下的判断可能不同（DJI_0009 0:44：脚跟先着地 / 全脚掌）。试过加长判断窗口、扣除每只脚的偏置，在 DJI_0009 上人工核对新旧判断不同的 12 次着地，能看清的 8 次里原判断对 7 次、新判断对 1 次，所以没有改。
- 30 fps 下一个启动步只有 3–5 帧；60 fps 素材更准。
- 启动步、起动、回位都以识别出的击球时刻和击球者为准，击球识别错了这些也会错（工作台修正击球后会自动重算）。
