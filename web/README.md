# RallyIQ web

单页 React 应用（Vite + TypeScript），对接 `rallyiq/api`（FastAPI）。

## 界面结构

- **侧栏导航**（可收起，工作台里默认收起）：比赛库、球员档案；打开某个视频后多出“回放与纠错 / 赛后报告”两项。每页顶部是面包屑 + 标题 + 当页操作。
- **比赛库**（`#/`）：概览数字（视频数、已完成分析、分析中、累计时长）、上传区和“上传 → 自动分析 → 复核纠错 → 报告与档案”流程说明、视频列表（状态、打开、报告、删除）、难例统计。
- **回放与纠错**（`#/videos/<id>`）：三栏工作台 + 底部时间轴，功能见下。
- **赛后报告**（`#/videos/<id>/report`）：比分牌和全场指标、AI 教练点评、打法风格、比分走势、双方对比、逐回合、球员数据、写入档案；顶部分节导航可跳转。
- **球员档案**（`#/profile`）：长期指标走势（带迷你折线）、训练复测、最近变化、对手习惯。
- **登录页**：只在后端开启账号时出现。

设计规范在 `src/styles.css` 顶部：深色中性底、一种品牌强调色（只用于主操作、选中态和播放头）、颜色只表达含义（球员、羽毛球、状态）、数字用等宽数字、状态一律“圆点 + 文字”。

## 工作台功能

- 上传视频（显示上传进度），视频列表和分析任务状态（逐阶段进度轮询）
- 回放：原画 / AI 标注切换；双色骨架、羽毛球轨迹（实线 = 检测，虚线半透明 = 插值）、球场线、检测框，各层可开关、调透明度；"纯抽象"模式隐藏原画面，只在深色背景上显示识别元素
- 时间轴：时间刻度、回合色块（底边颜色 = 得分方，虚线框 = 待复核）、击球刻度（按击球者着色，待复核带橙色圆点），点击跳转，可放大到当前回合；慢放、逐帧
- 左栏：分析概览（回合、击球、待复核、已修正）、视频与标定状态、比赛类型（自动识别 / 强制单打 / 强制双打，切换后从球员识别重跑）、跑位热力图（单打 P1/P2；双打 P1–P4 或按队伍 A/B，整段或当前回合，标定可靠时才显示跑动米数）、手动点选球场四角重新标定
- 右栏：球场小地图（带 2 秒轨迹）、当前回合与击球列表、纠错、修正记录、导出
- 顶栏：单/双打、“下一个待复核”按钮（快捷键 `n` / `Shift+N`）、快捷键面板（`?`）
- 击球类型：击球列表和时间轴（放大回合时）显示类型，虚线框 + `?` 表示待复核；选中一拍可看置信度、候选、待复核原因和判断依据，并一键改类型或确认；左栏按球员统计类型分布（整场 / 当前回合）和"最近一拍"
- 纠错（全部追加写入，原始预测保留）：增 / 删 / 移击球、改击球者、改击球类型、确认；改回合起止、删除 / 新建 / 确认回合、设得分方；从某帧起交换 P1/P2（双打可选队内 P1↔P3、P2↔P4 或跨队交换）；双打得分方按队伍记。默认勾选"记为难例"（`hard_example`）
- 导出 JSON（生效事件 + 原始预测 + 修正）、逐拍 CSV 和当前回合的视频片段（MP4，前后各留 1 秒）

快捷键：`空格` 播放/暂停，`←` `→` 逐帧，`J` `K` 上/下一拍，`[` `]` 上/下回合。

## 运行

```bash
# 后端（仓库根目录）
pip install -e '.[dev]'
RALLYIQ_DEMO=1 uvicorn rallyiq.api.app:app --port 8000

# 前端
cd web
npm install
npm run dev          # http://localhost:5173 ，/api 代理到 :8000（RALLYIQ_API 可改）
```

不启动后端也能看界面：打开 `http://localhost:5173/?mock`（或 `VITE_USE_MOCK=1 npm run dev`），使用前端生成的合成数据，修正存在浏览器 localStorage。

```bash
npm test             # vitest：纠错逻辑与后端 contracts/examples 一致性、单应性、热力图、CSV
npm run build        # 类型检查 + 生产构建到 web/dist
```

## 代码结构

| 文件 | 内容 |
| --- | --- |
| `src/styles.css` | 设计系统：颜色 / 间距变量、按钮和表单、导航框架、卡片、各页通用组件样式 |
| `src/styles/*.css` | 各页自己的补充样式（`home` / `report` / `profile` / `workbench`） |
| `src/components/ui.tsx` | 通用组件：图标、页头（面包屑 + 标题 + 操作）、页面框架、统计卡、空状态 |
| `src/App.tsx` | 侧栏导航 + 路由 |
| `src/lib/types.ts` | 与 `rallyiq/contracts/models.py` 对应的接口类型 |
| `src/lib/api.ts` | 真实 API 客户端 + 离线 mock 实现 |
| `src/lib/strokes.ts` | 击球类型名称、颜色、原因码翻译、按球员统计、`mergeStrokes` |
| `src/lib/corrections.ts` | `rallyiq/api/corrections.py` 的 TS 移植（mock 模式用），有一致性测试 |
| `src/lib/overlay.ts` | Canvas 叠加层绘制 |
| `src/lib/clock.ts` | 统一播放时钟（有视频用 `<video>`，无视频用虚拟时钟） |
| `src/lib/mock.ts` | 确定性合成数据（含漏检、误检、击球者错误，便于演示纠错） |
| `src/lib/mockProfile.ts` | 演示模式的合成球员档案 |
| `src/pages/Home.tsx` | 比赛库 |
| `src/pages/Workbench.tsx` | 三栏工作台 |
| `src/pages/Report.tsx` | 赛后报告 |
| `src/pages/Profile.tsx` | 球员档案 |
