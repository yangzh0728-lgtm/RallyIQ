# 打法风格分析（`rallyiq/report/style.py`）

赛后报告里的“打法风格”回答四个问题：这位球员（双打为这一队）**偏向哪种打法**、**为什么这样判断**、
**执行得是否到位**（主动 / 中立 / 被动时的选择、各战术套路的胜率），以及**面对这个对手下一拍该怎么选**。

全部在本机计算，只用规则，不调用任何模型或云服务。打法标签没有足够的标注数据可训练，所以每种打法写成一个
**原型**：一组可测量特征和“偏高 / 偏低”的方向，把球员的数据和每个原型做匹配，得到 0–100 的吻合度。

## 1. 研究依据

| 研究 | 用到的结论 |
| --- | --- |
| Laffaye, Phomsoupha & Dor (2015) *Changes in the game characteristics of a badminton match: a longitudinal study through the Olympic Game finals analysis in men's singles*. J Sports Sci Med 14(3):584–590 | 奥运男单决赛：网前球 25–35%、挑球 23–27%、杀球 10–14%、平抽 1–5%，高远球从 18% 降到 3%；回合 10–13 s；击球频率 0.9→1.3 拍/秒；得分方式：直接得分 36%、受迫失误 23%、主动失误 41% |
| Valldecabres, De Benito, Casal & Pablos (2017) *2015 Badminton World Championship: singles final men's vs women's behaviours*. JHSE 12(3proc) | 男 / 女单决赛：网前 36% / 28%、挑球 22% / 19%、高远球 11% / 14%、吊球 7% / 12%、杀球 11.5% / 9.4%、平抽 4.5% / 8.9%；每回合 6.5 / 5.4 拍；斜线移动约占一半，后场斜线移动最有效 |
| Sheng, Yi, Gómez-Ruano & Chen (2022) *The influence of technical and contextual variables of the last stroke on point outcome in men's and women's singles badminton*. Front Psychol 12:802179 | 把击球按意图分为进攻（有得分意图）和防守；防守性的最后一拍显著降低直接得分概率、提高失误概率（男单失误边际效应 +0.46）；高远球和挑球随情境可攻可守 |
| Wang et al. (2021) *ShuttleNet: position-aware fusion of rally progress and player styles for stroke forecasting in badminton*（ShuttleSet） | 75 场高水平单打、43,191 拍，平均每回合约 10 拍；用每位球员的击球序列学习“风格”并预测下一拍，说明击球序列 + 位置足以刻画风格 |
| Zhao et al. (2025) Front Sports Act Living 7:1634573（网球） | 用归一化熵衡量技战术多样性，本项目借来衡量“同一位置出球落点的多样性” |

参考区间（下表的“0 分 → 100 分”）大多锚定在这些职业单打数字附近。业余比赛的分布会不同，所以结论只写成“接近 / 偏向”，
并同时给出同场对手的数值方便比较。

## 2. 每一拍的攻防状态

按用户给的“实时战术决策”定义，但单机位 30 fps 看不到击球点高度和身体平衡，所以用**来球**代替：

| 状态 | 判断（来球） | 推荐打法 |
| --- | --- | --- |
| 主动 | 对手挑球；或对手在被动状态下打的高远球 | 杀球、点杀、劈吊、抢网、连续进攻 |
| 被动 | 对手杀球或扑球 | 高质量解围、接杀挡网、快速回位、防守反击 |
| 中立 | 其他 | 四角调动、直线控制、拉吊组织、节奏变化 |

**进攻性击球** = 杀球、扑球、推球，或主动状态下的吊球（劈吊）和平抽。
报告按状态列出每人打了什么、符合推荐打法的比例；逐拍建议（`ShotMoment.phase`）也带上当时的状态，交给教练模型按状态给建议。

## 3. 特征（`<Pn>.style.*`，双打为 `A.style.*` / `B.style.*`）

| 特征 | 含义 | 参考区间 |
| --- | --- | --- |
| `smash_pct` `net_pct` `clear_pct` `drop_pct` `clear_drop_pct` `flat_pct` `lift_block_pct` | 击球构成（不含发球） | 杀球 5–20%，网前 15–40%，高远 5–20% … |
| `attack_pct` / `defense_pct` | 进攻性击球占比 / 被动状态击球占比 | 10–35% |
| `convert_pct` | 主动状态下选择进攻的比例（抓机会） | 30–80% |
| `attack_run` | 连续进攻的平均拍数（连续下压） | 1–2.5 |
| `early_attack_pct` | 前两拍就进攻的回合占比（抢攻） | 15–60% |
| `build_attack_pct` | 先连续两拍高远 / 吊球再突击的回合占比（拉吊突击） | 10–50% |
| `counter_pct` / `hold_pct` | 被动后两拍内转入进攻 / 被动时没有直接丢分 | 10–50% / 60–95% |
| `attack_win_pct` / `attack_err_pct` | 进攻后两拍内得分 / 进攻直接失误（需标注胜负） | 15–50% / 5–30% |
| `flight_s` `tempo_cv` `accel_pct` | 出球到对手击球的中位时间、快慢变化、突然加速（比前几拍的中位间隔快 35% 以上） | 0.7–1.3 s，25–60，5–25% |
| `opp_reach_m` `corner_pct` | 对手接球的移动距离、把对手调到四角的比例（需球员跟踪） | 1.2–2.8 m，30–70% |
| `straight_pct` | 从边路出球时打直线的比例 | 40–80% |
| `variety` | 同一击球区域出球落点的熵（0–100，欺骗性的代理指标） | 40–80 |
| `forced_pct` | 逼对手挑球 / 挡网或直接得分的比例 | 10–40% |
| 双打：`fb_pct` `fb_attack_pct` `sbs_defense_pct` `fixed_front_pct` `smash_conc_pct` `front_kill_pct` | 一前一后站位、进攻时前后站位、防守时左右站位、固定一人在前、杀球集中在一人、网前封扑 | |

另外复用已有指标：`match.rally_len.mean`（每回合拍数）、`Pn.win.long_rate_pct`（长回合胜率）、
`Pn.win.lost_own_last_shot_pct`（失分时最后一拍是自己的比例，近似主动失误）。

“落点”用的是**对手下一拍的击球位置**（羽毛球落点没有识别），与站位相关的特征在球场标定未确认时降为“待复核”。

## 4. 打法原型

| 打法 | 代表 | 特征（↑ 偏高，↓ 偏低，数字为权重） |
| --- | --- | --- |
| 强攻压制型 | 安赛龙、李梓嘉 | 杀球↑3，进攻占比↑2，连续进攻↑2，主动转化↑2，逼对手被动↑1，被动占比↓1 |
| 速度抢攻型 | 李宗伟、马林 | 前两拍抢攻↑3，出球时间↓2，平抽推压↑2，进攻占比↑1，网前↑1 |
| 拉吊突击型 | 林丹、石宇奇 | 拉吊占比↑3，先拉吊再突击↑3，对手移动距离↑1，进攻得分↑1，前两拍抢攻↓1 |
| 控制组织型 | 桃田贤斗、陈雨菲 | 直线比例↑3，网前↑2，逼对手被动↑2，主动失误↓2，杀球↓1 |
| 防守反击型 | 谌龙、昆拉武特、安洗莹 | 被动时顶住↑3，防守后反击↑3，被动占比↑2，挑球+挡网↑1 |
| 多拍消耗型 | 奈良冈功大、奥原希望、山口茜 | 每回合拍数↑3，长回合胜率↑2，主动失误↓2，对手移动距离↑1，进攻占比↓1 |
| 技术欺骗型 | 戴资颖、因达农 | 落点多样性↑3，逼对手被动↑2，对手移动距离↑2，网前↑1 |
| 节奏变化型 | 安东森、林丹、石宇奇 | 快慢变化↑3，突然加速↑3，拉吊占比↑1 |
| 双打·后场强攻型 | 兰基雷迪/谢提 | 杀球↑3，连续进攻↑2，进攻时前后站位↑2，杀球集中在一人↑1 |
| 双打·平抽快挡型 | 吉迪恩/苏卡穆约 | 平抽推压↑3，出球时间↓3，前两拍抢攻↑1 |
| 双打·网前预判控制型 | 阿山/塞蒂亚万 | 网前封扑↑3，网前球↑2，前后站位↑1 |
| 双打·防守转换型 | 松友美佐纪/高桥礼华 | 被动时顶住↑3，防守后反击↑2，被动占比↑2，防守时左右站位↑1 |
| 双打·混双前封后攻型 | 郑思维/黄雅琼 | 固定一人在前↑3，前后站位↑2，杀球↑1 |

吻合度 = Σ 权重 × 匹配度 / Σ 权重。匹配度把特征按参考区间线性映射到 0–1（“偏低”的特征取 1 − x），
再按样本量向 0.5（中性）收缩：`0.5 + (匹配度 − 0.5) × n / (n + 10)`，几拍的偶然结果不会决定打法；
样本少于 5 的特征直接按 0.5 计入，超过一半权重测不到时不打分。结论规则：

- 已分类的非发球击球少于 20 拍 → “证据不足”；20–79 拍为“待复核”，80 拍以上为“可用”。
- 单打里相邻两拍应由不同球员击出。交替比例低于 80% 时可信度降为“低”并提示修正击球者；低于 60%
  （接近随机）时不给结论，标为“证据不足（击球者识别不可靠）”。
- 最高分 < 60 → “均衡型（没有明显倾向，最接近……）”。
- 第二名与第一名相差 ≤ 5 分 → “A（兼 B）”。

技术欺骗型只能间接判断：真正的假动作需要看引拍和对手重心，单机位视频目前只能看“同一位置出球方向是否多变、对手是否被迫多跑”。

## 5. 六种战术套路（单打）

| 套路 | 识别规则 |
| --- | --- |
| 四角调动 | 连续三拍都让对手移动 ≥ 1.8 m |
| 网前逼起球 | 自己放网 / 勾对角 → 对手挑球 → 自己进攻 |
| 拉吊突击 | 之前三拍里既有高远球又有吊球、最近两拍没有进攻 → 杀球 / 劈吊 / 扑球 |
| 防守转攻 | 被动状态击球后两拍内进攻 |
| 重复落点陷阱 | 从边路连续两拍直线 → 一拍斜线 |
| 节奏破坏 | 前几拍中位间隔 ≥ 0.8 s，这一拍出球时间不到其 65% |

每个套路统计次数、所在回合胜率（只算已标注胜负的回合）、对手被迫挑球 / 挡网或直接丢分的比例，并给出前三次的视频时间方便回看。

## 6. 建议从哪里来

`PlayerStyle.advice` 是规则建议，按顺序：

1. **执行**：主动时进攻比例偏低、被动时顶不住、防守后很少反击、进攻失误多、中立时挑球太多。
2. **套路**：胜率最高 / 最低的套路（至少 3 个有胜负的回合）。
3. **学习对象**：打法明确时给出代表球员和学习重点。
4. **针对对手**：对手打法明确时给出克制思路；再根据对手的回球习惯（例如“接你的吊球 70% 放网”）提示下一拍的预判。

AI 教练（本地 Ollama 或离线模板）会收到精简后的打法数据，用 `<Pn>.style.*` 指标作依据写打法点评；
防编造校验照常生效。主动转化低、被动顶不住、进攻失误多也会作为训练重点去检索教学笔记。

## 7. 局限与下一步

- 攻防状态由来球推断，没有用到击球点高度和身体平衡；接入姿态（手腕高于头部、重心）后可以更准。
- 落点用对手下一拍的击球位置近似；有羽毛球落点后直线 / 斜线和四角会更准。
- 参考区间来自职业单打；积累了足够多的个人比赛后，可以改成按个人历史或同水平球员的分布做标准化。
- 有了一些人工确认的打法标签后，可以用这些特征训练轻量模型（例如逻辑回归），原型作为先验。
