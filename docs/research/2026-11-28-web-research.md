# 网上调研：对 RallyIQ 有用的论文和开源项目（2026-11-28）

范围：2023–2026 年关于羽毛球（及网球、乒乓球、足球）球跟踪、击球时刻检测、人体姿态与 3D、多人跟踪、球拍姿态、击球类型、球场标定、LLM 教练报告的论文、GitHub 仓库和数据集。已在 `awesome-badminton-survey.md`、`github-topic-badminton-survey.md`、`accuracy-sources.md` 里出现过的不再重复。

做法：
1. 三路并行调研，共看了约 80 个工作，详细报告见本目录 `2026-11-28/` 下三份文件。
2. 另起 8 个独立核查，逐条去读 LICENSE 文件、论文正文和 README，核对仓库是否存在、许可证、权重是否真的公开、标题数字是否对得上。下文已按核查结果修正。
3. 再读一遍 RallyIQ 代码，确认每条建议接在哪个文件哪一行、是否已经做过（见 `2026-11-28/code-mapping.md`）。

没有实际跑任何外部代码；数字均来自论文或 README。

## 一、结论：按瓶颈列出要做的事

排序原则：先做不需要新模型、不需要新许可证的；再做需要下载外部 MIT/Apache 权重的；GPL/AGPL/非商用的只借思路。

## 二、我做的决定（按 sam 的要求，不再逐项询问）

1. **许可证红线**：GPL/AGPL/非商用/无许可证的代码和权重不并入产品，只借思路或按论文自己实现；无许可证的数据集只做内部评测。具体：T-DEED（GPL-3.0）、ETH 羽毛球检测（AGPL-3.0）、PnLCalib/NBJW（GPL）、SMPL 系 3D、Sapiens、TrackNetV5、UMEG-Net 代码、kwyoke 数据、VideoBadminton、BadminSense 都在此列。
2. **RacketVision 可以先下载评估**（代码 MIT），但它的 HF 权重没有声明许可证、训练画面是 YouTube 转播；上线前要么得到作者许可，要么用自家视频标几百帧重训。
3. **优先做不需要外部模型的四件事**：方向特征改成机位无关、挥拍证据进打分器、拖影中点标注规则、网页手动四角走线吸附。这些已发给对应的训练线程。
4. **不追 TrackNetV5**：相对 V3 提升不到 1 个点，且没有可用许可证。
5. **3D 先不做**，等 2D 姿态和击球检测稳定后再评估 GEM-X。

## 三、核查时发现的更正（原始调研里说错或说过头的）

- “双打论文击球人准确率 0.6686”：实际是“是否击球”的二分类帧准确率，论文没有单独报告击球人准确率。
- “网球发球姿态识别球员 99.2%”：只适用于发球 ≥100 次的 14 名球员（闭集），不是全部 109 人。
- RacketVision 的 88.5% 是多项目联合模型，单项目羽毛球模型 82.1%。
- TrackNetV5（NYCU）仓库里**有**权重，但无许可证，且是复现版（F1 98.36，不是论文的 98.47）。
- AdaSpot 摘要写网球 +3.96，正文写 +3.98，论文自相矛盾，不影响结论。
- VideoMAE V2 权重已改为公开、标 Apache-2.0，不再需要填表。
- TennisTV 最新版（v5）数字：GPT-4.1 45.1%，人类 89.2%。
- DoublesEval 正文和表格数字不一致，具体数值不可靠。
- Roboflow BadmintonC 最新版本 2,536 张，不是 3,647；且标注可能是框，不是角点。
