## 概述

移动是成为好球员的基础，而每一步移动之前都要有启动步：双脚轻微离地、落地成宽站姿，重心低，像有人从后面拉你的髋。上正手网前：启动步后左脚先小幅调整，再左-右-左（左脚用两次）上步。退后场：启动步后以左脚为轴转体（右手持拍者），侧身、保持高肘，根据距离用并步（他称“丹麦式 shuffle”，也有人叫马来西亚步）退到位，再用右腿蹬地发力。全程要低、放松，不要僵硬。

## 具体步法

- 启动步：小跳离地，落地宽站姿，重心低、髋向后坐，双脚平行
- 上正手网前：启动步 → 左脚小幅调整 → 左-右-左上步（左脚用两次）
- 退正手/头顶后场：启动步 → 以左脚为轴转体侧身 → 并步（他称丹麦式 shuffle，也叫马来西亚步）后退 → 右腿蹬地击球
- 后退时双脚保持距离，不并拢；全程放松

## 动作分解

- **启动步**：跳得低而快，宽站姿
- **上网节奏**：左-右-左，最后一步右脚弓步
- **后退**：以左脚为轴转身，侧身对网，高肘，并步后撤，距离越远蹬地越用力
- **身体状态**：低重心、放松，僵硬会浪费体能

## 技术要点

- 每一次移动前都要做启动步：小跳、落地成宽站姿。
- 启动步不要跳太高，稍微离地即可；站得低，想象有人从后面拉你的髋。
- 双脚站位要平行，不要右脚过于靠前。
- 上正手网前：启动步 → 左脚小幅调整 → 左-右-左上步（左脚用两次）。
- 退后场：启动步 → 以左脚为轴转体、侧身 → 并步后退 → 右腿蹬地击球；保持高肘。
- 后退时双脚不要并得太近，要保持步幅和支撑面。
- 后退距离决定需要多大的蹬地力量。
- 移动要放松、重心低；僵硬会浪费体力，放松才能节省能量。

## 使用时机

- 每一拍之前（对手击球瞬间）都要做启动步

## 常见错误

- 启动步跳得太高。
- 站得太直太高，重心不够低。
- 上网少了一步或多走一步，步伐顺序混乱。
- 退后场时“走”过去而不是转体并步，或双脚并得太近。
- 全身过于紧张僵硬。

## 纠错实例

| 问题 | 安赛龙的提示 | 效果 |
|---|---|---|
| 启动步跳太高 | 低一点，稍微离地就行 | 启动更快 |
| 站太高太直 | 想象有人从后面拉你的髋，站得更深 | 重心降低 |
| 上网少一步/多一步 | 左脚要用两次 | 步伐顺序正确 |
| 后退时走过去、双脚并拢 | 转身后并步，双脚保持距离 | 后退更快更稳 |
| 全身僵硬 | 上下身都放松 | 更省体力 |

## 练习方法

- **原地启动步**：宽站姿、低重心，反复做小幅启动步，检查双脚平行、落地稳定。
- **启动步 + 上网**：从中场做启动步，按左-右-左节奏上到正手网前，逐渐加快。
- **启动步 + 退后场**：启动步后以左脚为轴转体、并步退到后场，保持高肘，做挥拍模仿。

## 进阶顺序

1. 原地启动步
2. 启动步 + 上正手网前
3. 启动步 + 退后场（转体并步）
4. 全场多点移动
